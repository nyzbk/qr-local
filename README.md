# Mark — Free QR Code Generator

Custom QR codes in the browser. URL, WiFi, vCard, colors, logo. PNG + SVG.

- 100% client-side (`qrcode` + Canvas). Nothing is uploaded.
- No signup, no watermark, no daily limit.
- Live: [qr-local.vercel.app](https://qr-local.vercel.app)

## Privacy

Payloads (URLs, WiFi passwords, vCards, logos) never leave this tab.
